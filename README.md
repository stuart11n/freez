# FREEZ

Browser port of FREEZ (c) Digital Synapse 1996, a DOS platformer originally written in Borland C with inline x86 asm.
This is a direct JavaScript translation of the source (no emulator): VGA mode 13h is a canvas, the DAC palette and
retrace waits are emulated at 70Hz, and the asm routines are rewritten function by function.

## Run

Serve this folder with any static HTTP server and open `index.html`:

    python -m http.server

## Controls

Arrows move, Ctrl / Z / Up jump, Alt / X / Shift fire, Enter / Space select, P pause, Esc quit to menu.
F1 sound, F2 weather, F3 parallax. Debug keys from the original: L end level, T timer, A steam, S die.

## Notes

- Only level 1 data exists in the shipped game; finishing it returns to the menu.
- Sound is hooked up to the original WAVs via Web Audio (the shipped DOS build had it compiled out).

## Original source

The original Borland C / TASM source is in `original/` (CP437 encoded; `FREEZE.CPP` is the entry point).

## 2026 version (also the mobile version)

`2026/` is a separate, enhanced build (it plays on desktop and phones; `mobile/` just redirects here): the frame is upscaled to 640x480 (Scale2x, stretched to 4:3), it has on-screen touch
controls (d-pad, fire, jump, OK / pause / menu), works in portrait and landscape, and has an optional CRT scanline
effect (CRT button, or F6 on a keyboard). Serve the repo and open `2026/index.html`.

### 2026 build extras

- **Display:** WebGL shader with two scaling filters (Pixel / Smooth) and three CRT modes (Off / Scanlines /
  Full CRT is the default: curvature, beam scanlines, phosphor mask, bloom, vignette). Falls back to a 2D canvas without WebGL.
  Settings panel via the gear button; hotkeys F6 (CRT), F7 (scaling), F8 (music).
- **Tracker music:** a small ProTracker-style player: songs are order lists of patterns written as text rows (note,
  instrument, volume, effect), 6 ticks per row, 8-bit looped waveforms and drum samples, hard-panned Amiga-style stereo,
  and per-tick effects (arpeggio, vibrato, slides, note cut). Five in-game songs (the first plays a random one, then every minute it fades out and fades in a different track), a menu song, and win and game over jingles; all
  synthesised with Web Audio, no audio files.
- **Night:** the clouds fade to dark slate with the sky, and the night storm has low-key distant thunder.
- **Level intro:** the level intro screen is held for an extra second.
- **End screens:** win screen with fireworks and a time-bonus tally, and a game over screen.
- **Longer level 1:** the shipped level had no end flag and an unfinished, floorless hall in its lower left. The 2026
  build finishes it: the hall is now a long corridor with pits, spikes and blocks, ending in a shaft that drops into a
  new long lower lane (springs, moving platforms, a restart flag and the end flag). Generated by
  `2026/tools/gen_level.py` from the original maps; the level timer was extended to match.
- **Jump inertia:** in the air you keep your horizontal speed. Holding the direction you are moving speeds you up
  quickly (as in the original, so jump distance is unchanged), but the wings steer with damping: opposite
  direction brakes and turns within about 0.3 s, and letting go bleeds the speed off smoothly. Holding a
  direction as you take off commits you to at least walking speed. Landing hands the speed back to the ground code.
- **Enemy voices:** birds squawk and the yellow hoppers squish as they land, quieter and panned by distance when they
  are near. Synthesised, no audio files.
- **Wing flap:** press jump again in the air (twice per airtime) to flap your wings for a small extra boost in height.
- **Intro card:** the TV-tuning title sequence now tunes in a new "DIGITAL SYNAPSE presents" card (generated by `2026/tools/make_intro.py`) before the FREEZ menu.
- **Coins** bounce a little in place.
- **Rain** eases in and out and varies between drizzle and downpour while the storm lasts.
- **Tree birds:** fly behind a tree's front foliage and 20% of the time a few small blue birds (drawn in code, half size) burst out of it, with squawks.
